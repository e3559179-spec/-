# 怎样从原文形成解释

随读答疑、读后讲解以及复核解释时使用。此方法用于约束和核对解释，不保证模型不会误读；不能因为完成了这些检查，就声称解释已经被独立证实。

已有知识可帮助辨认概念和提出候选解释，但不能替代当前文本证据。给用户展示清楚的解释、关键原文依据与必要的推论关系，无需把下列步骤全部排成固定栏目。

## 1. 确定语句、声音和范围

先处理用户指定的文字；结合实际可访问的必要上下文，确认：

- 谁在说话：作者、自引、被转述者、批评对象、译者注还是编者按？某观点出现在书里不等于作者赞同它。
- 谁在做什么：“这”“它”等指代什么？长句中的主干、修饰和省略分别是什么？只解释用户所需的难点，不把每个语法成分都列出来。
- 说到什么程度：保留否定、转折、时间、对象、条件和范围。特别注意“只有”“并非”“某种”“在……条件下”等词，不把必要条件解释成充分条件，不把局部判断扩大为普遍判断。
- 文本在做什么：定义、描述、举例、设问、反驳、类比或推导？一个例子不必然构成一般规律，一段描述也不必然构成规范主张。

若扫描或 OCR 可能漏掉否定词等关键文字，先核验原页；无法核验则指出哪些解释取决于该文字。引文与工作段落编号按 [原文规则](source-rules.md) 处理。

## 2. 在这里解释概念

先找当前句、段及已获得上下文中的定义、对比、例子和用法，再解释概念在本处的作用。不要看到“实践”“物质”“异化”等词就用教材定义替换本段分析。

同一个词可能有日常用法、作者特定用法或论战中的限定用法；概念含义也可能随论证展开。已有定义可作参考，但仍要说明它是否适用于本处。

需要借助前文而前文缺失时，说清当前可确定的部分，以及需要哪段文字才能进一步判断。不要声称作者“前面已经证明”实际上未读到的内容。没有原语言文本和可靠依据时，不自行还原德文等原词或宣称译者误译。

## 3. 展开论证，保留缺口

根据本段性质，回答作者在处理什么问题、提出什么判断、给出哪些理由、理由怎样支持结论。叙述、例证或过渡段可按其实际作用解释，不强行给每段套上三段论。

区分三类内容：

| 内容 | 表达要求 |
| --- | --- |
| 文本明示 | 指出相关短语或句子及其位置。准确转述，不扩大其断言范围。 |
| 助手重建 | 原文未说出的连接或隐含前提，明确使用“可以这样理解”“这里可能预设”等表述，说明重建的文本理由。 |
| 尚不确定 | 连接有缺口、两种读法都能成立或上下文不足时，说明不确定在哪里，以及何种材料有助判断。 |

若原文从 A 跳到 C，不能仅因 B 能使论证顺畅，就把 B 当成作者已经论证过的命题。可以给出一种可能重建，但保留“B 是否成立”的问题；没有足够依据时直接指出目前不能确认两者如何衔接。

类比、先后相继和共同出现，不自动构成因果或必然推论。用户问“论证成立吗”时，分别说明作者的推导意图与该推导是否充分，不为了替作者辩护而补入未经支持的前提。

## 4. 回到文字检验读法

形成解释后，核对它是否：

- 能说明所解释范围内的重要文字，没有避开不利于该读法的句子；
- 保留条件、否定、论述对象与说话者身份；
- 与实际读到的前后文相容，没有把未获得的上下文当作已知；
- 没有用作者其他时期、其他著作或后来的理论概括替代当前文本；
- 将“作者说什么”“这一说法是否成立”“用户是否赞同”分开。

若有另一种有文本依据的解释，比较各自能说明的文字和困难；依据更强时可以明确倾向一种读法，不必把所有读法说成同样合理。自己想到的备选读法不等于已存在的学术流派，未经核验不要冠以学界共识或某学者观点。

## 5. 给出可核对、可修正的说明

先用贴近问题的语言解释，再指出决定性文字和必要联系。常识性的简短释义不必附一长串来源；关键论断、直接引文和有争议的解释要能回到当前原文位置。

为帮助理解所作的例子、比喻或结构图，明确是助手举例，不能作为作者原意的证据。通俗改写仍须保留限制条件；“通俗”不能成为删掉理论关系的理由。

若使用文本之外的材料，把它作为背景补充列出实际来源、核验范围及局限。核验不了的背景不承担核心解释，不用模型熟悉感代替来源。

## 解释被质疑时

用户给出反例、不同读法或更多上下文后，重新核对相关文字。不要要求用户先接受上一版解释，才允许讨论。

- 助手误读：明确指出之前哪一点不成立、依据什么修正、哪些解释受到影响。按 [记录格式](record-schema.md) 追加解释及 `history` 纠错事件，保留旧内容，不将其归因于用户理解不足。
- 有依据的不同理解：指出共有部分和分歧，不以用户没有复述助手用词判错。
- 用户的说法超出原文：给出具体限制或反证，区分可保留部分与需修改部分。
- 材料仍不足：保留争议或待解决状态，说明还缺什么，不强行裁定。

助手旧解释有误时，复核依赖它的检查结论；无可靠依据的旧评价不能继续作为掌握证据。只有助手提供了新解释、用户尚未重新表达时，不记录“用户已经修正”。
